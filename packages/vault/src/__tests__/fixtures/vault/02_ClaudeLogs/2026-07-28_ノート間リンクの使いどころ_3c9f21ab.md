# ノート間リンクの使いどころ

[[Claude Log]]

### 🧑 自分

ノートを[[]]で繋ぐ機能って、フォルダ分けと何が違うの

### 🤖 Claude

違いは一点だけです。フォルダは**置き場所を一つに決める**仕組みで、リンクは**関係を後から足せる**仕組みです。`[[用語集]]` と書いた瞬間に、用語集の側からも戻ってこられる道ができる。この戻り道がバックリンクです。

## 効いてくる場面

**1. 入口が複数になる**

`Orbit` というノートを1枚だけ用意して、作業メモの本文で `[[Orbit]]` と書いておく。Orbit を開けば、言及しているメモが下に一覧で出ます。同じメモを `[[設計メモ]]` からも `[[用語集]]` からも辿れる、というのがフォルダとの決定的な差です。

**2. 空のリンクを先に置ける**

`[[並び替えの仕様]]` は実体がなくても書けます。未作成のリンクとして薄く表示されるので、「あとで書く」の付箋代わりになる。手を止めずに印だけ置けるのが効きます。

**3. 名前を変えても壊れない**

ノート名を変更すると、参照している側の `[[]]` がまとめて追随します。相対パスで書いていたら壊れる場面です。

**4. タグとの役割分担**

- タグ = 縦の分類（`#下書き` `#未読`）。そのノート自身の属性。
- リンク = 横の関係。ノートとノートの間にある事実。

分類は最初に体系を決めないと破綻しますが、関係は後からいくらでも足せます。輪郭が定まっていないテーマほどリンク向きです。

### 🧑 自分

毎回[[]]を打つのが面倒。後からまとめてできない？

### 🤖 Claude

できます。**標準機能だけ**で足ります。

## 未リンクのメンション

サイドバーのバックリンク欄の下に「リンクされていないメンション」が並びます。ここに出るのは、**ノート名を地の文で書いただけ**のノートです。

つまり `[[Orbit]]` と打たずに「Orbit で試した」と書いておけば十分で、あとで Orbit のノートを開き、各行の **Link を押すと `[[]]` に変換**されます。一括変換もあります。

## 表記ゆれは aliases で吸収する

frontmatter に別名を並べておくと、どの表記で書いてもメンションが拾えます。

```markdown
---
aliases: [Orbit, オービット, 周回ノート]
---
```

`[[` の補完も別名から引けるので、和英が混ざる語ほど効果があります。

## 注意

メンション検出はただの文字列一致なので、`メモ` のような短い語のノートを作ると全部がヒットしてノイズになります。効くのは `Orbit` や `並び替えの仕様` のような固有性の高い語です。

運用としては「全部を繋ごうとしない。**ハブになるノートを十数枚だけ**用意して、あとは地の文で書き、たまに一括リンク化する」くらいがちょうどいいです。
